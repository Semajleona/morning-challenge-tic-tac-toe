About the Project

This is a classic Tic-Tac-Toe game built using HTML, CSS, and JavaScript.

Two players take turns placing X and O on a 3x3 game board. The game checks the board after each turn to determine if a player has won or if the game ends in a draw.

The project also includes a Reset Game button that clears the board and allows the players to start a new game.

🎮 How to Play
Player 1 starts as X.
Click an empty square to place an X.
The turn automatically switches to Player 2, who plays as O.
Players continue taking turns.
Get three matching symbols in a row, column, or diagonal to win.
If all spaces are filled without a winner, the game ends in a draw.
Click Reset Game to clear the board and start over.
🛠️ Tech Stack
HTML5

HTML is used to create the structure of the game, including the title, nine game squares, and Reset Game button.

CSS3

CSS is used to style the game and create the 3x3 grid layout. It also controls the board size, colors, borders, text size, background image, and Reset Game button.

JavaScript

JavaScript controls the game logic and makes the application interactive
